# Overlay-gen

## Что это

Оверлей — беззвучный клип 1080×1920 с плотным слоем частиц на чистом чёрном
фоне. Он накладывается на видео через Screen/Add и должен заметно менять
картинку. Редкая пыль бесполезна: частицы обязаны заполнять большую часть
кадра.

Партия — 10 клипов = 10 новых промптов = один новый профиль
`overlay/profile_N`. Профиль расходник: следующая партия получает следующий
номер. `overlay/profile_1` (100 старых клипов) не трогать.

## Главное правило

Пользователь говорит только «нужны 10 новых оверлеев» — этого достаточно.

- Тему не спрашивать: 10 тем придумывает агент.
- Промпты пользователю не показывать и отдельного «ок» не ждать.
- Прислать короткий dry-run **для информации**: 10 эффектов, формат, время,
  цена. Ответа не ждать и сразу запускать.
- Остановиться только при реальной поломке, превышении бюджета или если ни
  один клип не прошёл плотность.
- В конце прислать zip и визуальное превью в Telegram.

## Плотность — главный критерий

В промпте всегда несколько слоёв частиц и заполнение кадра:

- «thousands of», «dense», «thick», «crowded», «packed», «throughout the
  entire frame», «covering the whole frame»;
- разные размеры и поведение: искры, хлопья, капли, осколки, пыль, шарики,
  волокна;
- движение медленное, но заметное: падение, подъём, завихрение, боковой
  поток, вращение;
- обязательный хвост: `on pure black background, slow motion, no camera
  movement, no people, no text`;
- только латиница, без кириллицы.

QA по доле ярких пикселей (`ffmpeg`, серый кадр, порог 50):

| Класс | Доля | Что делать |
|---|---|---|
| брак | < 0.3% | перегенерировать |
| слабо | 0.3–3% | перегенерировать |
| норма | 3–10% | в архив |
| плотно | ≥ 10% | в архив |

Слабое и брак переделываются на том же сервере с новым seed, до 3 попыток.
В архив и в Telegram попадают только «норма» и «плотно».

## Промпты: как придумывать

1. Взять 10 разных материалов/явлений, а не 10 оттенков одного эффекта.
2. Проверить по всей базе `overlay/profile_*/backgrounds.txt` (250 строк).
3. Сходство ≥ 0.85 — блок, промпт заменить. 0.75–0.85 — предупреждение,
   лучше заменить. Сравнение игнорирует общий хвост и порядок слов.
4. Внутри партии промпты тоже не должны быть похожи друг на друга.

Примеры удачных направлений (не повторять дословно): феррожидкостные
капли-иглы, пенопластовые шарики в статике, облако тонера, аэрогелевая
крошка, диатомит, пемза, рыбья чешуя, хитиновые осколки жуков, лишайник,
люминесцентные бусины. Главное — плотность и заполнение кадра.

## Команды

Все команды — внутри контейнера, из `/root/dockers/content-factory`.
Пока код не в образе, монтируется исходник:

```bash
cd /root/dockers/content-factory
docker compose run --rm --no-deps \
  -v /root/dockers/content-factory/src:/app/src \
  worker python -m content_factory.services.generator.overlay_cli next
```

Дальше `CLI` — эта же команда с нужным подкомандным словом.

1. `next` — напечатает следующий свободный профиль, например
   `overlay/profile_17`.
2. Агент пишет 10 промптов в
   `/root/dockers/content-factory/app_data/overlay_requests/profile_17.txt`
   (на хосте; в контейнере это `/app/app_data/overlay_requests/profile_17.txt`,
   по одному промпту на строку) и проверяет:
   ```bash
   CLI check --prompts-file /app/app_data/overlay_requests/profile_17.txt
   ```
   Блоки заменяются и проверка повторяется до «блокирующих совпадений нет».
3. Создать профиль:
   ```bash
   CLI create --prompts-file /app/app_data/overlay_requests/profile_17.txt \
     --name overlay/profile_17
   ```
   Без `--name` возьмётся следующий свободный.
4. Dry-run:
   ```bash
   CLI plan --profile overlay/profile_17 --verbose
   ```
   Показать пользователю короткую сводку: формат, 10 эффектов, время,
   бюджет. Промпты — только если он сам попросил.
5. Запуск:
   ```bash
   CLI run --profile overlay/profile_17
   ```
   Берёт общий `GENERATOR_LOCK`, арендует один сервер Vast.ai, генерирует
   отсутствующие клипы, переделывает слабые, упаковывает zip и превью.

`run` можно повторять: готовые клипы, прошедшие QA, не генерируются заново.
`--force` — только по прямой просьбе переделать всё.

### Prefect

`overlay_batch` добавлен в `prefect.yaml` и принимает `profile`, `dry_run`,
`force`. Для ручного запуска достаточно CLI; flow нужен для статуса и
будущего расписания.

## Упаковка и выдача

`run` складывает результат в
`app_data/generated/overlays/<profile>/`:

- `<profile>_1080x1920.zip` — 10 клипов 1080×1920, h264, без звука;
- `preview.mp4` — по 1 секунде с каждого клипа, 540×960;
- `1080x1920/` — отдельные файлы.

В Telegram отправить через скилл `telegram-send`:

- zip как документ (до 2 ГБ);
- `preview.mp4` как видео;
- короткая подпись: профиль, 10 клипов, 1080×1920, без звука, диапазон
  плотности.

## Бюджет и сервер

- Один сервер на партию. L40S, `max_cost` профиля — $1/час.
- Ожидание: 15–25 минут, $0.1–0.3 за 10 клипов.
- Если оценка выше $1 или сервер дороже $1/час — остановиться и сказать.
- `VastSession` пишет журнал серверов и гасит инстанс в `finally` с проверкой.
  После прогона убедиться, что инстансов 0.
- `GENERATOR_LOCK` общий с дейтинг-генератором: две партии одновременно не
  арендуют серверы.

## Границы

- Дейтинг-пайплайн, сток, архивы и выдачу партнёра не трогать.
- Оверлеи не попадают в `/api/v1/content`, `content/<niche>/<lang>` и
  партнёрские архивы. Это отдельный цех ассетов.
- `overlay/profile_1` со 100 промптами не менять.
- Промпты и профили живут в runtime `app_data/profiles/overlay`, в git их
  нет.

## Если что-то сломалось

- `run.json` в папке профиля: план, seed, плотности, отклонённые клипы,
  пути архива.
- `videos/` — исходники; `generated/overlays/<profile>/` — упаковка.
- Повторный `run` доделает только отсутствующие клипы.
- Сервер не отвечает или задание висит — не ждать: `run` сам гасит сервер
  по таймауту, осиротевшие инстансы добивает `generator_recovery`.
- Если все клипы слабые — не отправлять архив, показать плотности и
  перегенерировать с `--force` или новыми промптами.
